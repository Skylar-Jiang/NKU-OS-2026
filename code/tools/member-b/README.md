# Lab5 成员 B 专项测试（2413507）

覆盖官方 13 个用户程序无法直接触达的路径：非法 ELF、装载过程中内存耗尽、已有用户地址空间时 exec（程序映像位于旧用户空间）、exit/wait/kill 的进程树与资源回收，以及 fork/COW 下的进程生命周期。

| 文件 | 内容 |
| --- | --- |
| `test_lab5_b.c` | 内核态测试，注入到 `init_main` 入口执行（68 项检查） |
| `b_cowlife.c` | 用户态测试程序，作为 `TEST` 程序运行（20 项检查） |
| `run.sh` | 复制源码到临时目录、注入测试、构建并运行 QEMU，不修改源码树 |

运行（在 `code/` 目录）：

```bash
sh tools/member-b/run.sh
```

内核态测试内容：

- 13 种畸形 ELF（魔数、截断、`e_phentsize`、程序头越界、`p_filesz > p_memsz`、偏移溢出、内核地址段、地址回绕、入口不在可执行段、段与用户栈重叠、段间重叠、无 `PT_LOAD`）：均返回错误，当前进程映像不变，空闲页数不变。
- 剩余 0~300 个空闲页时装载 testbss：返回 `-E_NO_MEM`，已分配的页表、页面、VMA 全部回收。
- 内核线程 exec 后检查页表/`satp`、进程名截断、trapframe（入口、用户栈顶、`SPP=0`、`SPIE=1`）、代码段 R-X、BSS 全零且 RW-、用户栈 VMA 与预分配页。
- 已有 mm 时从用户内存中的映像 exec：非法指针被拒、失败后旧映像可用、成功后旧 mm 被释放。
- `do_wait` 回收与退出码、重复等待、`do_wait(-1)`、`do_kill` 非法参数及保护 initproc、等待中被 kill、孤儿进程移交 initproc 后回收，以及整轮页数守恒。

依赖：完整运行需要成员 A 的计时器调度标记与 COW 写异常接入、成员 C 的 `print_pgdir`（见集成说明）。
