# Lab1 AI 使用与 Prompt 说明

本次 Lab1 主要针对已有最小内核进行编译、运行、源码阅读及 QEMU/GDB 调试，**没有使用 AI 生成或修改实验源代码**，因此没有形成代码生成任务对应的最终 Prompt、代码迭代与修复记录。

实验过程中，AI 主要用于辅助理解 RISC-V 内核启动流程、解释 Makefile 和调试命令、梳理实验步骤，以及检查和整理报告表述。内核实际运行结果、地址、寄存器数值与调试截图均以小组实际操作和验证为准。

因此，本次不逐项记录代码生成 Prompt。AI 辅助工作的简要说明亦见 [`report.md` 第 6.4 节](./report.md#64-ai-协作过程)。
